LOCAL SIMULATION LAB

Playground

所有实验都在浏览器本地运行：不需要 API Key，不调用真实 Jev API，模拟数值不代表真实模型输出。目的是建立对分布、阈值、校准和路由策略的直觉。

① Choice② Score③ Noul ④ Probability⑤ Calibration ⑥ Judgment Builder⑦ Agent Routing

① Choice Playground

自定义选项与模拟概率，观察概率分布、p_max、confidence 与阈值策略。

概率分布

② Score Playground

定义有序 rubric，输入样本，查看模拟等级分布、加权 score 与 confidence。

等级分布

③ Noul Playground

命题为真的概率 p 本身就是信号。观察 yes / no 倾向与不确定区间。

真假倾向

④ Probability Explorer

同时比较多个问题的概率分布。格式：问题名: p1,p2,p3。

⑤ Calibration Lab

生成模拟预测样本，按置信度分桶，绘制可靠性图并计算 Brier Score 与 ECE。

模拟数据声明：以下样本由浏览器伪随机生成，用于演示指标计算方法，不是 Jev 的真实预测或独立评测结果。

⑥ Judgment Builder

创建多个判断，设定概率与阈值，定义确定性组合规则，观察最终执行路径。

⑦ Agent Routing Lab

模拟 Tool / Model / Skill Routing、Confidence Gate、Human Approval 与 Fallback。
